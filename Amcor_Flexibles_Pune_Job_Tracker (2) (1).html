Enable online sync

This website works in local mode immediately. To sync jobs between computers, connect a Supabase project. The settings below are saved only in this browser.

  1. Create a project at Supabase.
  2. Open SQL Editor and run the supabase-schema.sql file included in this ZIP.
  3. In Project Settings → API, copy the Project URL and publishable/anon key below.

Important: This starter uses a public browser key. Configure sign-in and restrictive Row Level Security policies before storing real company/customer data. Do not put a service-role key here.
